Surge-dip: a two-leg paper-trading bot for the pump.fun bonding-curve replay. It buys breakouts on accelerating buy pressure and dips that are still being bought, sizes small first and adds only into strength, and cuts losers on a stop, a trailing stop, or a time limit. Paper trading only — no real funds.

## Run it

```sh
node main.ts
```
